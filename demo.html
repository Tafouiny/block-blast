📖 Comment utiliser

1 Configurez votre grille
Cliquez sur les cases pour marquer celles qui sont déjà remplies dans votre jeu Block Blast.
  • Case blanche = vide
  • Case bleue = remplie
  • Utilisez le bouton "Mode: Placer/Effacer" pour changer de mode
2 Sélectionnez vos blocs
Choisissez les 3 blocs qui vous sont proposés dans le jeu parmi la palette de formes.
  • Cliquez sur un bloc pour le sélectionner
  • Vous pouvez sélectionner le même bloc plusieurs fois (ex: 3x carré 2x2)
  • Un badge numéroté indique combien de fois un bloc est sélectionné
  • Maximum 3 blocs simultanément
  • Utilisez le bouton X pour retirer un bloc sélectionné
3 Trouvez la solution
Cliquez sur le bouton "🎯 Trouver la meilleure solution" pour obtenir:
  • L'ordre optimal de placement des blocs
  • La position exacte pour chaque bloc
  • Le score prévu pour chaque action
  • Le nombre de lignes qui seront complétées
4 Appliquez dans le jeu
Suivez les instructions étape par étape pour placer vos blocs dans Block Blast et maximisez votre score!

💡 Astuces et Conseils

  • Vérifiez bien votre grille: Assurez-vous que la configuration dans le solveur correspond exactement à votre jeu
  • Identifiez les bons blocs: Prenez le temps de bien identifier les formes proposées dans Block Blast
  • Priorité aux lignes complètes: Le solveur privilégie les placements qui complètent des lignes pour maximiser le score
  • Utilisez le mode effacer: Si vous faites une erreur, basculez en mode "Effacer" pour corriger facilement
  • Sauvegardez vos configurations: Prenez une capture d'écran de votre grille configurée pour référence future

❓ FAQ

Pourquoi certains blocs ne peuvent pas être placés?

Si la grille est trop remplie ou si la forme du bloc ne correspond à aucun espace disponible, le solveur vous indiquera qu'il ne peut pas placer tous les blocs.

Le solveur fonctionne-t-il hors ligne?

Oui! Une fois la page chargée, tout fonctionne localement dans votre navigateur sans connexion internet.

Puis-je utiliser moins de 3 blocs?

Absolument! Vous pouvez sélectionner 1, 2 ou 3 blocs selon vos besoins.

Le score prédit est-il exact?

Le solveur calcule le score basé sur les règles standard de Block Blast (10 points par ligne complète + bonus combo). Certaines variations du jeu peuvent avoir des règles légèrement différentes.
