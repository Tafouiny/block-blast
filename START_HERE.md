# 🚀 Démarrage Rapide - Block Blast Solver

Bienvenue! Voici comment utiliser le solveur en 3 étapes simples.

## 📖 Option 1: Guide Visuel Interactif (RECOMMANDÉ)

**Double-cliquez sur `demo.html`** pour accéder au guide complet avec exemples visuels, FAQ et tutoriels.

## 🎮 Option 2: Utiliser Directement l'Application

1. **Double-cliquez sur `index.html`** - L'application s'ouvre dans votre navigateur
2. **Configurez votre grille** - Cliquez sur les cases pour marquer celles qui sont remplies
3. **Sélectionnez vos blocs** - Choisissez jusqu'à 3 blocs parmi les 36+ formes disponibles
4. **Obtenez la solution** - Cliquez sur "Trouver la meilleure solution"

## 🧪 Option 3: Vérifier que Tout Fonctionne

**Double-cliquez sur `test.html`** pour lancer les tests automatiques et vérifier que tous les composants fonctionnent correctement.

## 🎯 Cas d'Usage Typique

### Exemple: Vous jouez à Block Blast

1. **Situation**: Votre grille est à moitié remplie, vous avez 3 nouveaux blocs
2. **Action**:
   - Ouvrez `index.html`
   - Reproduisez votre grille en cliquant sur les cases
   - Sélectionnez vos 3 blocs dans la palette
   - Cliquez sur "Trouver la meilleure solution"
3. **Résultat**:
   - Vous obtenez l'ordre optimal de placement
   - Les positions exactes pour chaque bloc
   - Le score prévu
   - Les lignes qui seront complétées

### Temps estimé: **2-3 minutes** pour configuration + résolution
